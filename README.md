# Superstore Sales Analysis Dashboard

## 📊 Project Overview

This project analyzes Superstore sales data to uncover key **sales, profit, product, customer, and regional performance insights**. The data was cleaned and preprocessed using **Python (Pandas)** and visualized through an interactive **Power BI dashboard**.

## 🎯 Key Objectives

* Analyze overall sales and profitability performance
* Identify top-performing categories and markets
* Understand regional sales trends
* Track key business KPIs
* Generate actionable insights through interactive visualizations

## 📈 Key Insights

* **Total Sales:** $12.64M
* **Total Profit:** $1.47M
* **Total Orders:** 25K
* **Top Category:** Technology — $4.74M revenue
* **Top Market:** United States — $2.3M sales

## 🛠️ Tools & Technologies

* **Python** — Data Cleaning & Preprocessing
* **Pandas** — Data Manipulation
* **Power BI** — Dashboard & Data Visualization
* **EDA** — Exploratory Data Analysis
* **KPI Analysis** — Business Performance Tracking

## 📊 Dashboard Features

* Sales and Profit KPIs
* Category & Sub-Category Analysis
* Regional & Market Performance
* Product Performance Analysis
* Interactive Filters & Slicers
* Dynamic Data Visualizations

## 💡 Business Insights

The analysis highlights the major revenue and profitability drivers across categories and markets, helping identify high-performing areas and supporting **data-driven business decisions**.
